# Código de conduta

Este código vale para issues, pull requests, discussões e qualquer outro espaço do Pulso.

## O que esperamos

- Comente o código e a ideia, com clareza e respeito.
- Aceite correção. Peça correção com o mesmo cuidado.
- Dê contexto suficiente para outra pessoa reproduzir um problema.
- Respeite o tempo de quem mantém o projeto. Nem toda ideia entra.

## O que não é aceito

- Ataque pessoal, insulto ou humilhação.
- Assédio, intimidação ou contato indesejado.
- Discriminação por origem, gênero, orientação, deficiência, religião ou idade.
- Publicação de informação privada de outra pessoa.
- Spam, propaganda ou issues abertas só para promover outro produto.

## Onde isso se aplica

Nas ferramentas do repositório e quando alguém representa o Pulso em outro espaço. Conduta fora do projeto só entra aqui quando a pessoa está falando em nome dele ou quando o comportamento atinge quem participa daqui.

## Como reportar

Abra um aviso privado em [Security advisories](https://github.com/araguaci/pulso/security/advisories/new) e descreva o que aconteceu, quando e onde. Não publique o relato numa issue aberta.

Quem mantém o repositório lê o aviso, pode pedir mais detalhe e responde com uma decisão: nenhuma ação, aviso, ou bloqueio de participação. A decisão é registrada para as pessoas envolvidas.

## Atribuição

Este texto segue o espírito do [Contributor Covenant](https://www.contributor-covenant.org/) 2.1, escrito de forma direta para este projeto.
